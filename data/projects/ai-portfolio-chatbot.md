# 자기소개 AI 포트폴리오 챗봇

## 한 줄 소개
- 면접관이나 방문자가 나에 대해 질문하면, 내 자료를 찾아서(RAG) AI가 대신 답해주는 챗봇

## 기간과 인원
- 2026년 11월, 3일 개인 프로젝트 (비트고급 과정 개인 프로젝트)
- 기획, 자료 정리, 코드 작성, 화면 개발, GitHub 관리까지 혼자 진행

## 만든 이유
- 이력서나 GitHub만으로는 내 프로젝트를 자세히 설명하기 어려움
- 면접관이 궁금한 것을 바로 물어보고 답을 들을 수 있게 하고 싶었음
- 수업에서 배운 LangChain과 RAG를 실제 서비스 형태로 만들어 보고 싶었음

## 사용 기술
- 언어: Python 3.12
- RAG 구성: LangChain, Chroma(벡터 DB)
- AI 모델: Ollama로 내 컴퓨터에서 실행
  - 답변 모델: qwen2.5:3b
  - 임베딩 모델: bge-m3 (한국어 지원)
- 화면: Streamlit
- 버전 관리: Git, GitHub

## 동작 순서
- 1단계: data 폴더의 자료(.md 파일)를 읽음
- 2단계: 자료를 500글자 정도의 조각으로 나눔
- 3단계: 조각을 숫자(벡터)로 바꿔서 Chroma 벡터 DB에 저장
- 4단계: 질문이 오면 질문과 가장 비슷한 조각 4개를 찾음
- 5단계: 찾은 조각만 보고 AI가 답변을 만듦
- 6단계: 답변과 함께 참고한 자료 이름(출처)을 보여줌

## 주요 기능
- 채팅 화면에서 질문하고 답변 받기
- 답변마다 참고한 자료(출처) 표시
- 자료에 없는 내용은 지어내지 않고 "해당 내용은 자료에 없습니다"라고 답함
- 추천 질문 버튼으로 바로 질문하기

## 왜 RAG를 썼는지
- 일반 AI는 나에 대한 정보를 모르기 때문에 그냥 물어보면 틀린 답이나 지어낸 답을 함
- RAG를 쓰면 내가 넣은 자료에서 찾아서 답하기 때문에 정확함
- 프로젝트가 늘어나도 자료 파일만 추가하면 됨
- 답변마다 출처를 보여줄 수 있어서 믿을 수 있음

## 왜 Ollama를 썼는지
- OpenAI, Gemini, Ollama를 비교해 보고 Ollama를 선택함
- 비용이 들지 않음
- 내 컴퓨터 안에서만 돌아가서 자료가 외부 서버로 나가지 않음
- 다만 컴퓨터 성능을 많이 쓰기 때문에 가벼운 3b 모델을 선택함
- 설정 파일(.env)의 한 줄만 바꾸면 Gemini나 OpenAI로도 바꿀 수 있게 만듦

## 지어내지 않게 만든 방법
- AI에게 "자료에 있는 내용만 말하라"는 규칙을 줌
- 자료에 답이 없으면 정해진 문장으로만 답하게 함
- 경험이나 실력을 부풀리지 말라는 규칙도 넣음
- 답이 일정하게 나오도록 창의성(temperature)을 0으로 설정함

## 자료 정리 방법
- 프로젝트마다 파일을 따로 만듦
- 파일 첫 줄에 제목을 쓰고, 소제목으로 내용을 나눔
- 조각마다 문서 제목을 붙여서, 어느 프로젝트 이야기인지 AI가 헷갈리지 않게 함
- GitHub 저장소들을 읽고 실제 있는 내용만 자료로 정리함

## 보안과 Git 관리
- .gitignore로 설정 파일(.env), 가상환경, 벡터 DB가 GitHub에 올라가지 않게 막음
- 처음 커밋 전에 git check-ignore 명령으로 .env가 제외되는지 확인함
- 단계마다 커밋해서 작업 기록을 남김

## 어려웠던 점과 해결 방법
- 문제: Git 명령어를 처음 써봐서 git add.처럼 띄어쓰기를 틀림
- 해결: 에러 메시지를 읽고 git add .으로 고쳐서 해결
- 문제: 터미널에서 cd 없이 폴더 경로만 입력해서 permission denied 에러가 남
- 해결: 폴더로 이동할 때는 cd 명령어가 필요하다는 것을 알고 고침
- 문제: OpenAI는 유료, Gemini 무료 버전은 사용 횟수 제한이 있어서 어떤 AI를 쓸지 고민함
- 해결: 비용이 없고 자료가 밖으로 나가지 않는 Ollama를 선택함

## 한계와 앞으로 개선할 점
- 내 컴퓨터에서만 실행돼서 다른 사람이 링크로 접속할 수는 없음
- 앞 질문을 기억하지 못해서 "그거 더 자세히"처럼 이어서 묻는 질문은 잘 못 알아들음
- 작은 모델이라 한국어 문장이 가끔 어색할 수 있음
- 앞으로 Gemini로 바꿔서 인터넷에 배포하고, 대화 기억 기능을 추가하고 싶음
