
# TodayDo 팀 프로젝트

## 한 줄 소개
- 일정과 날씨를 한 번에 보여주는 일정 관리 프로그램
- 활동 장소의 기상청 예보를 일정에 연결하고, AI가 준비물과 대체 활동을 조언해 줌

## 기간과 인원
- 2026년 11월, 3인 팀 (비트고급 4조)
- 나는 팀장을 맡음

## 대회
- 2026년도 하반기 SW중심대학 오픈소스 AI·SW 활용 경진대회 프로토타입 분야 출품

## 사용 기술
- 화면(클라이언트): C#, WPF (.NET 9), WebView2
- 서버: ASP.NET Core Web API (.NET 9), Entity Framework Core, Swagger
- 데이터베이스: MySQL
- 지도: 카카오맵 API
- 날씨: 기상청 단기예보 API (공공데이터포털)
- AI: Claude API

## 주요 기능
- 회원별 일정 등록, 수정, 삭제, 완료 처리
- 날짜별 일정 검색
- 지도에서 장소를 검색하거나 클릭해서 활동 위치 설정
- 일정 시간과 장소의 기온, 강수확률, 강수량 조회
- 날씨 예보가 바뀌면 앱 안에서 알림
- AI가 일정과 날씨를 보고 활동 적합성, 준비물, 대체 활동을 제안

## 구조
- WPF 화면이 ASP.NET Core 서버에 요청하고, 서버가 MySQL, 기상청 API, Claude API와 연결됨
