# 통신사 고객 이탈 예측 실습

## 한 줄 소개
- 통신사 고객 데이터를 보고, 그 고객이 서비스를 떠날지(이탈) 예측하는 머신러닝 프로젝트

## 기간과 인원
- 2026년 11월, 수업 실습 과제, 개인

## 사용 기술
- Python, pandas, scikit-learn, matplotlib, Jupyter Notebook

## 데이터
- IBM에서 공개한 통신사 고객 이탈 데이터 (Telco Customer Churn)

## 한 일
- 데이터 전처리: 숫자 데이터는 빈칸을 중앙값으로 채우고 표준화, 글자 데이터는 원-핫 인코딩
- 모델 5개 비교: 로지스틱 회귀, SGD, 결정 트리, 랜덤 포레스트, 그래디언트 부스팅
- 성능 비교 지표: 정확도(Accuracy), 정밀도(Precision), 재현율(Recall), F1 점수
- 교차 검증과 GridSearchCV로 랜덤 포레스트 최적 설정 찾기
- 이탈 고객을 놓치지 않는 게 중요해서 재현율(Recall)을 기준으로 최적화함

## 코드 구성
- 같은 과정을 두 가지 형태로 만듦
- 파이썬 파일 버전: 기능별로 파일을 나눔 (전처리, 모델별, 성능 비교 등)
- 주피터 노트북 버전: 실습 1~11단계와 최종 과제 보고서
